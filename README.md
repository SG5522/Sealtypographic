取章排版系統

=====================================================

注意事項

1.Spire.Pdf.dll .NET Standard 2.0 是使用官網下載的dll

因為Nuget上沒有此板本只有.NET 6。

另外也保留.NET6的環境 專案名稱DJSpireNET6


2.目前天創元件因為無法多人運作以及64位元下執行，

需要對天創提出以下需求:

1.需要32位元與64位元版本

2.原圖轉換的BMP檔預設放在系統的temp資料夾並可以指定路徑

3.分離產生的圖檔可以指定路徑

4.2與3產生的圖檔要能多工(多人使用時不要因為檔名一樣互相覆蓋)

5.可以指定特定範圍進行分離

6.可以直接輸出圖檔資料或byte[]

7.印鑑圖檔要能轉正

8.程式的CONFIG路徑要能使用相對路徑而不是程式路徑
